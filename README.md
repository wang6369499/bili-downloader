# B站视频下载器（网页版 · 跨平台）

一个带图形界面的 B站视频下载工具：批量粘贴链接 → 自动下载并把 DASH 音/视频流合成为 **H.264 + AAC 的 MP4**（手机 / 微信 / 浏览器全兼容）。
后端基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，ffmpeg 由 `imageio-ffmpeg` 自动提供，**无需本机另行安装**。

支持 **Windows** 与 **macOS**（Linux 亦可）。

---

## 快速开始

### macOS / Linux
```bash
cd bilibili_downloader
./run.sh
```
首次会自动创建 `.venv` 并装好依赖，随后自动打开浏览器 `http://127.0.0.1:9876`。

### Windows
双击 `run.bat` 即可（或在文件夹里 Shift+右键「在此处打开命令窗口」后运行 `run.bat`）。
首次会自动创建 `.venv` 并装依赖，随后自动打开浏览器。

>  prerequisites：本机需安装 Python 3.10+ 并已加入 PATH（Windows 安装时务必勾选 “Add python.exe to PATH”）。

---

## 界面功能
- **批量下载**：链接框每行一个（支持 BV号 / 完整链接 / b23.tv 短链），一次提交多个。
- **画质选择**：最佳 / 1080P / 720P / 480P / 360P / 仅音频(MP3)。
- **实时进度**：每个任务独立卡片，显示进度条、速度、剩余时间、已下载/总量。
- **取消 / 清空**：可随时取消正在下载的任务，或一键清理已完成/失败的记录。
- **打开输出文件夹**：一键在文件管理器里定位已下载文件。
- **设置项**：输出目录、字幕开关、限速、合集下载开关。
- **设置记忆**：点「💾 保存为默认设置」把 cookie / 输出目录存到 `config.json`，下次启动自动载入，不用每次手填。

## UP主视频勾选下载

界面顶部切换到「👤 UP主视频」：

1. 填入 UP主空间链接 或 纯 UID（如 `https://space.bilibili.com/546195` 或直接 `546195`），设定「获取数量」（默认 30，上限 200）。
2. 点「🔍 获取视频列表」→ 列出该 UP主最新视频（标题、时长、播放量、发布日期、BV号）。
3. **逐条勾选**想要的内容（可「全选」/「全不选」），点「⬇️ 下载选中」批量加入下载队列。

也支持 B站**合集 / 收藏夹 / 系列**链接，用法相同：粘贴链接 → 获取列表 → 勾选 → 下载。

> ⚠️ **这个功能通常需要 cookie。** B站对空间列表接口有风控，未登录会返回 352 / 412，列表拉不出来。
> 若看到「B站风控/限流拒绝了该请求」，请按下一节配置 cookie 后重试；
> 若已配置仍失败，多半是请求太频繁，歇一会儿再试。
> 实在拉不出列表时，可用「🔗 视频链接」模式手动粘贴多个 BV号，批量下载同样可用。

## 高画质 / 会员 / 番剧（必须登录态）

B站 1080P 高码率、大会员、番剧需要登录态。两种方式二选一：

0. **直接粘贴（最省事，推荐）** —— 不用装插件、不用导出文件
   - 浏览器打开 `https://www.bilibili.com` 并登录。
   - 按 `F12`（Mac 用 `⌥⌘C`）打开开发者工具 → 切到「网络 / Network」→ 刷新页面。
   - 点第一个请求 → 在「请求标头 / Request Headers」里复制 `Cookie:` 后那一整串。
   - 粘进界面「⚙️ 下载设置 → ✋ 或直接粘贴 Cookie」框里，点「📋 保存这份 Cookie 并设为默认」。
   - 程序会自动转成 Netscape 格式存为 `cookies.txt` 并写入 `config.json`，下次启动自动载入。
   - 保存后会提示是否包含 `SESSDATA` —— 有它才说明是有效登录态。

1. **cookie 文件（最稳）**
   - 安装浏览器插件「cookie-editor」。
   - 打开 `https://www.bilibili.com` 并登录，点击插件 → 导出为 **Netscape** 格式，保存为 `cookies.txt`。
   - 在界面「设置 → cookie 文件」里填入该文件路径（如 `C:/bili/cookies.txt` 或 `~/bili/cookies.txt`）。
2. **读取浏览器登录态**
   - 在「设置 → 读取浏览器登录态」选择 Chrome / Edge / Firefox。
   - 注意：macOS 上需先在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」给终端/运行器授权，否则读不到浏览器数据；Windows 需关闭浏览器或允许读取。

## 打包成独立程序（免安装 Python）

打包后得到**双击即用**的独立程序，拷到任何同系统的电脑上都能跑，对方不需要装 Python。

> ⚠️ **PyInstaller 不能跨平台打包**：要 Windows 的 `.exe` 必须在 **Windows** 上执行打包；要 macOS 的 `.app` 必须在 **macOS** 上执行。在哪台机器上打包，就得到那个平台的产物。

### Windows → exe
1. 在 Windows 上装好 Python 3.10+（安装时勾选 **Add Python to PATH**）
2. 把整个 `bilibili_downloader` 文件夹拷过去
3. **双击 `build.bat`**，等 3–8 分钟
4. 产物：`dist\B站下载器.exe`，双击运行，自动打开浏览器界面

### macOS → app
```bash
cd bilibili_downloader
chmod +x build.sh
./build.sh
```
产物：`dist/B站下载器.app`

### 打包后的文件位置
程序会把**可写数据放在程序旁边**，不会写进临时目录（这点已专门处理）：

| 内容 | 位置 |
|---|---|
| 下载的视频 | exe / .app 同目录的 `downloads/` |
| Cookie | 同目录 `cookies.txt` |
| 默认设置 | 同目录 `config.json` |

### 体积与启动
- 因为内置了完整 yt-dlp（上千个站点解析器）和 ffmpeg，产物约 **80–150MB**，属正常。
- onefile 模式每次启动有 2–5 秒解压时间，属正常。
- **杀毒软件可能误报**，这是 PyInstaller 打包的普遍现象，加白名单即可。

## 常见问题
- **下载后是 AV1/HEVC？** 不会。脚本强制优先选 H.264(avc1)，合成 MP4 兼容性最好。
- **端口被占用？** 服务会自动寻找 9876 之后的空闲端口，看终端输出的实际地址。
- **想换输出目录？** 在界面设置里填绝对路径即可，留空用默认的 `downloads/`。
- **停在「合成中」？** 小视频正常，ffmpeg 正在把音视频流封装成 MP4，稍等即可。
- **UP主列表提示风控（352 / 412）？** B站空间接口要求登录态且有频率限制。请配置 cookie 后重试；仍失败多半是请求太频繁，歇一会儿再试。**最省事的是在设置里把「读取浏览器登录态」选成你正在登录 B站的浏览器**（Chrome / Edge / Firefox），不用手动导出文件。
- **下载被中断，留下 `.f30080.mp4` / `.f30280.m4a` / `.part` 等中间文件？** 前两个是已下完的音视频分片，`.part` 是未完成的分片。若音视频分片都齐了，可手动补封装（几秒完成，不必重下）：
  ```bash
  ffmpeg -i "xxx.f30080.mp4" -i "xxx.f30280.m4a" -c copy "xxx.mp4"
  ```
  确认最终 MP4 能正常播放后，中间文件即可自行删除。
